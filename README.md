TTH's Assistant legal pages
===========================

Files:
- index.html
- terms.html
- privacy.html

Publish:
1. Upload all three HTML files to the root of the public GitHub repository.
2. In repository Settings > Pages, select Deploy from a branch.
3. Select branch main and folder /(root), then Save.
4. Wait for GitHub Pages to publish. Your URLs will be:
   https://tolgath.github.io/tth-assistant-legal/   
   https://tolgath.github.io/tth-assistant-legal/terms.html   
   https://tolgath.github.io/tth-assistant-legal/privacy.html

Important:
These are draft legal documents based on the currently understood bot implementation.
Verify the exact deployed code and update the Privacy Policy if you add or change storage,
AI providers, music providers, analytics, hosting, or other data processing. Consider
having the documents reviewed by a qualified legal professional before public launch.
